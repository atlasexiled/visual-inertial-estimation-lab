# Study collaboration

This repository is a learning lab. The learner implements the core algorithms
and discusses the mathematics, reasoning, and observed behavior.

- The assistant owns writing, adding, maintaining, and running tests. Do not ask
  the learner to write or add tests. Running existing tests is optional for the
  learner, not a prerequisite for receiving a review.
- The assistant owns all documentation, Markdown edits, reports, and progress
  tracking. Do not ask the learner to edit `.md` files or write reports.
- Gather explanations through conversation and document them on the learner's
  behalf. Record only demonstrated results; do not infer mastery from passing
  tests or mark unfinished work complete.
- Keep assignments focused on implementation and understanding. Provide hints
  and review; leave core exercise solutions to the learner unless requested.
- These responsibilities apply throughout the curriculum, including passages
  inherited from the original plan that mention testing or documenting results.
